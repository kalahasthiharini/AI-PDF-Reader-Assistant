# AI-PDF-Reader-Assistant

Reads PDFs and generates summaries using OpenAI's GPT models.  
This project extracts text from PDF files, splits them into chunks, and uses AI to provide concise summaries.

---

## 🚀 Features
- Extracts text from PDF documents.
- Splits large text into manageable chunks.
- Summarizes each chunk using OpenAI GPT.
- Combines summaries into a final document overview.
